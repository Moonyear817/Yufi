# 课堂录音笔记

用户在「课堂笔记」页面录课，录音在本机识别成文字稿。每门课是一个项目，每节课一个文件夹：

```
<课程项目>/课堂录音/<日期 时间>/
  录音.webm   原始录音
  文字稿.md   每句一行，行首是录音里的时间，如 [00:12:30]
  笔记.md     整理好的笔记（整理后才有）
```

## 指引

- 找课程：`dela list_workspace_entries '{"query":"课程名"}'` 找到课程项目与路径；当前会话就在课程项目里时直接用相对路径
- 文字稿由本机语音识别生成，可能有错字、同音字和断句问题，结合上下文与课程主题理解，不要照抄错字
- 整理笔记写入同一节课文件夹的 `笔记.md`：概要、按讲课顺序的知识点（术语保留英文并附中文解释）、老师强调的内容与可能考点、作业与截止时间、需要课后确认的地方
- 引用原话时带上文字稿里的时间，方便用户回听
- 文字稿很长时分段读取（read 的 offset/limit），不要一次读完整学期
- 不要修改 `录音.webm`；`文字稿.md` 只在用户要求更正时修改
